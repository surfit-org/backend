# 네이버 코딩 컨밴션 가이드

코드 스타일 통일을 위해 **네이버 코딩 컨밴션 v1.2** 를 적용합니다.
Gradle 빌드 시 자동 검사되며, IntelliJ에서 실시간으로 위반 사항을 확인할 수 있습니다.

---

### 현재 세팅 구조

이미 프로젝트에 적용되어 있는 항목들입니다. (별도 설정 불필요)

```
config/
├── checkstyle/
│   ├── naver-checkstyle-rules.xml       ← 네이버 규칙 파일 (v1.2)
│   └── naver-checkstyle-suppressions.xml ← 예외 처리 파일
└── formatter/
    └── naver-intellij-formatter.xml     ← IntelliJ 포맷터 설정 파일
```

- `./gradlew build` 실행 시 체크스타일 자동 검사
- 위반 시 콘솔에 경고 출력, `build/reports/checkstyle/main.html` 에 리포트 생성

---

### 팀원 필수 세팅 (최초 1회)

레포 클론 후 IntelliJ에서 아래 세 가지를 설정해야 합니다.

---

#### 1. 코드 스타일 포맷터 적용

`Cmd+Alt+L` (자동 정렬) 시 네이버 컨밴션 기준으로 포맷팅됩니다.

1. `Settings` (`Cmd+,`) → `Editor` → `Code Style` → `Java` 이동
2. 우측 상단 톱니바퀴 아이콘 클릭 → `Import Scheme` → `IntelliJ IDEA code style XML` 선택
3. 프로젝트 내 `config/formatter/naver-intellij-formatter.xml` 파일 선택
4. Scheme 이름 확인 후 `OK`
5. 상단 Scheme 드롭다운에서 방금 import한 `Naver-coding-convention-v1.2` 선택

---

#### 2. 저장 시 자동 포맷 설정 (권장)

저장(`Cmd+S`)할 때마다 자동으로 코드 정렬과 import 정리가 실행됩니다.
**이 설정을 하면 `Cmd+Alt+L`을 매번 누르지 않아도 됩니다.**

1. `Settings` (`Cmd+,`) → `Tools` → `저장 시 액션` 이동
2. 아래 두 항목 체크

   | 항목 | 설명 |
          |---|---|
   | ✅ `코드 서식 다시 지정` | 저장 시 네이버 컨밴션 기준으로 자동 정렬 |
   | ✅ `import 문 최적화` | 저장 시 미사용 import 제거 및 정리 |

3. `적용` → `확인`

---

#### 3. CheckStyle 플러그인 설정

IntelliJ 에디터에서 코드 작성 중 실시간으로 위반 사항을 표시합니다.

**플러그인 설치 확인**

1. `Settings` → `Plugins` → `CheckStyle-IDEA` 검색
2. 설치되어 있지 않다면 설치 후 IntelliJ 재시작

**규칙 파일 연결**

1. `Settings` → `Tools` → `Checkstyle` 이동
2. `Scan Scope` 를 `All Sources (Including Tests)` 로 변경
3. Configuration File 목록 하단 `+` 버튼 클릭
4. `Use a Local Checkstyle File` 선택
5. 경로에 `config/checkstyle/naver-checkstyle-rules.xml` 입력
6. `Next` 클릭 후 properties 추가

   | Key | Value |
          |---|---|
   | `suppressionFile` | `naver-checkstyle-suppressions.xml` |

7. `Finish` → `Active` 체크박스 활성화 → `Apply`

---

### 사용 방법

#### 코드 자동 정렬

저장 시 액션을 설정했다면 `Cmd+S` 저장만 해도 자동 정렬됩니다.

```
Cmd + S            ← 저장 시 자동 정렬 (저장 시 액션 설정한 경우)
Cmd + Alt + L      ← 수동으로 현재 파일 전체 정렬
```

#### 위반 사항 확인 (Gradle)

```bash
# 체크스타일만 실행
./gradlew checkstyleMain

# 빌드 전체 (체크스타일 포함)
./gradlew build
```

#### 위반 리포트 확인

빌드 후 아래 경로의 파일을 브라우저로 열면 파일별 위반 목록을 볼 수 있습니다.

```
build/reports/checkstyle/main.html
```

### 자주 발생하는 위반 예시

| 규칙                    | 잘못된 예              | 올바른 예          |
|-----------------------|--------------------|----------------|
| `list-uppercase-abbr` | `getOpenAPI()`     | `getOpenApi()` |
| `indentation-tab`     | 스페이스로 들여쓰기         | 탭으로 들여쓰기       |
| `no-trailing-spaces`  | 줄 끝에 공백 있음         | 공백 제거          |
| `newline-lf`          | CRLF 줄바꿈 (Windows) | LF 줄바꿈         |
| `max-line-length`     | 120자 초과            | 120자 이내로 줄바꿈   |

> 저장 시 액션을 설정했다면 `Cmd+S` 저장만으로 대부분의 위반이 자동 수정됩니다.

### 특정 코드에서 규칙 예외 처리

불가피하게 규칙을 무시해야 하는 경우 `config/checkstyle/naver-checkstyle-suppressions.xml` 에 추가합니다.

```xml

<suppressions>
    <!-- 예시: SwaggerConfig.java 전체 예외 -->
    <suppress files="SwaggerConfig.java" checks=".*"/>

    <!-- 예시: 특정 규칙만 예외 -->
    <suppress files="SwaggerConfig.java" checks="AbbreviationAsWordInName"/>
</suppressions>
```

> 남용 금지. 예외 추가 시 PR에 사유를 명시해주세요.
