# 백엔드 초기 세팅

처음 시작 시 로컬 개발 환경 세팅 가이드입니다.

---

### 준비물

- **Docker Desktop**
- **IntelliJ IDEA**
- **Java 21**

---

### Java SDK 21 설치 및 설정

우리 프로젝트는 **Java 21**을 기반

1.  **SDK 다운로드**: IntelliJ 상단 메뉴 `File` → `Project Structure` 이동
2.  **SDK 설정**: `SDKs` 탭 → `+` 버튼 → `Download JDK` 클릭
3.  **버전 선택**: **Version: 21** 선택 후 다운로드 및 적용
4.  **확인**: `Project` 탭의 SDK가 21로 설정되어 있는지 확인

---

### IntelliJ 플러그인 & 환경 변수 세팅

보안상 민감한 정보는 `.env` 파일로 관리하며, 이를 위한 전용 플러그인이 필요

#### **필수 플러그인 설치**
1.  `Settings` (Windows: `Ctrl+Alt+S` / Mac: `Cmd+,`) → `Plugins` 이동
2.  **EnvFile** 검색 후 설치 (프로젝트 실행 시 `.env`를 읽어오는 역할)
3.  **Lombok** 검색 후 설치 (이미 설치되어 있다면 패스)

#### **환경 변수(.env) 설정**
1.  백엔드 **루트 폴더**(`backend/`)에 `.env` 파일을 생성합니다.
2.  디스코드 **[환경 변수]** 채널에 올라온 내용을 그대로 복붙(변경될 수 있음)
3.  **실행 구성(Edit Configuration) 연결**:
    - 상단 실행 버튼 옆 `Edit Configurations...` 클릭
    - `EnvFile` 탭 선택 → **`Enable EnvFile`** 체크
    - `+` 버튼 클릭 → 아까 만든 **`.env`** 파일 선택 후 `OK`

### 인프라 실행 (Docker Compose)

DB를 직접 설치하지 않고 도커로 한 방에 띄우기

1.  터미널 열기. (위치: `backend/` 폴더)
2.  아래 명령어를 입력
    ```bash
    docker-compose up -d
    ```
3.  Docker Desktop 에서 실행 확인 or docker ps 명령어

### 세팅 완료 확인

다 했으면 서버 실행되는지 보기

-   **서버 로그**: `Started BackendApplication...` 문구가 뜨면 성공입니다.
-   **스웨거 API 확인**: 브라우저에서 [http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html) 접속
-   **테스트**: `Test API` 그룹의 `/ping` 호출 후 `pong`이 오는지 확인
